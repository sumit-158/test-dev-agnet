SCR-01 — Request workspace

User: SCO procurement data steward (desk, desktop). Primary job: decide whether the extraction is right and correct it in a few clicks. User stories: US-1 chat with attachments and later messages; US-2 request type first; US-3/US-4 line items with the PRD fields; US-5 split screen; US-8 conflicts; US-9 corrections by edit or chat. Features: v2/F-06 (shell, chat pane), v2/F-07 (line-item cards, edit, export button). The one bold element: the status word on every value (Missing / Conflict / Corrected) — everything else stays quiet.
State: ready — golden example extracted (default)

SCR-02 — Attachment viewer (opens in the left pane above the chat)

User: steward. Primary job: see why the AI chose a value — the page, the yellow box around the text, and the message span — without leaving the result. User stories: US-6 source per value (message or attachment page, text, box); US-7 click-to-evidence, several sources boxed, computed values show the computation; US-8 both sides of a conflict visible at once. Features: v2/F-08. Boxes are percentages of the rendered page image, so they stay on the text at 50 %, 100 % and 200 % zoom (PRD §7).
State: default — “Show source” on Amount line 1: popover with two sources; viewer open on page 1; the message span marked
